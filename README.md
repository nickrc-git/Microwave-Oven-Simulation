# Microwave Oven Simulation

## Overview
A microwave oven simulation implemented on PIC16F877A featuring Microwave, Grill, and Convection cooking modes. The system provides a menu-driven user interface with configurable cooking parameters, timer management, and status display through a character LCD.

## Features
- Microwave cooking mode
- Grill cooking mode
- Convection cooking mode
- Temperature selection
- Pre-heating functionality
- Countdown timer
- Pause and resume operation
- Buzzer notification
- LCD-based menu navigation

## Hardware Used
- PIC16F877A
- Character LCD
- Matrix Keypad
- Buzzer
- Timers
